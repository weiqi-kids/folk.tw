## 機制一覽

| 機制 | 位置 | 資料流 | 門檻／紅線 |
|---|---|---|---|
| 結果卡直達做圖 | 求籤結果卡 `cardcta` → 籤詩頁 `#qiancard` | — | 這是使用者主動點擊，允許錨點捲動 |
| 籤後選擇題 | 求籤結果卡（解籤之後、**非強制**） | `qian_choice` 事件（choice 維度）→ 聚合 `choices` | 統計句總量 ≥10 才顯示；選項是中性行動傾向，🔴 不涉籤意詮釋 |
| 大家在問什麼 | `/qiugian/pulse/` | qiugian-stats（GA4 近 7 天） | 百分比總量 ≥30 才顯示；「最多人抽到」該籤 ≥2 人才列 |
| 籤詩人格 | 籤詩頁 `#persona`＋結果卡一行 | `src/data/poem-personas.json`（8 型×215 首） | 🔴 原創閱讀框架、頁面明示非權威解釋；關鍵字必須是籤文原文連續片段（`check:integrity` 硬擋） |
| 同籤留言 | 籤詩頁「同籤的人留下的話」 | api.folk.tw `/v1/whispers`（送審制） | 🔴 個人經驗、不代表神明指示、不是解籤（區塊內明示）；全數人工審後刊出 |

## 同籤留言的運作（站方要做的事）

- 待審佇列：`/root/folk.tw-api/whispers/pending.jsonl`
- 審核：`cd /root/folk.tw-api && node review-whispers.mjs list`，
  `approve <id…>`／`reject <id…>`；核准即時刊出（前端 5 分鐘快取）。
- 伺服器端硬擋：2–80 字、含網址/email/電話樣式拒收；每 IP 每日 5 則；
  IP 只存 sha256 前 16 碼。`/about` 已載明審閱與匿名原則。
- ⚠️ 內容審閱照「負面結果的呈現」原則：涉及困境的留言可過，
  但引導性斷言、替人解籤、廣告一律退。

## 互動深度分層（不做人群分流）

第一層（所有人）：抽籤 → 籤詩 → 解籤，到此完整。
第二層之後全部是**自選**：選擇題、做圖、人格、同籤留言。
🔴 不要把任何互動做成求籤的前置步驟（顧問初版的「不立即顯示解籤」已被其修正版否定）。

## 觀測

各機制的事件（`qian_choice`／`qian_card`／`qian_card_ready`／`whisper_submit`）
與聚合欄位（`choices`／`_temples`／`_styles`）都進 `qiugian-stats.json`，
每 3 小時更新。要回答「哪個互動有人用」直接讀該檔，不用猜。
