# 神明比較：職司差異而非靈驗排名

「神明比較不是把信仰做成排行榜。比較時可以先看四個維度：神格或經典來源、民間常見職司、地方廟宇的主祀脈絡，以及當地廟方實際提供的儀式。媽祖常進入海洋守護與救苦救難的故事，觀音以慈悲救苦的佛教脈絡被理解，關聖帝君則同時有忠義、武神、商業與文衡等多重神格。這些內容可以幫讀者找到適合閱讀的入口，不能保證某位神明一定解決某個人的問題。

比較表每一格都要附來源與範圍；若是地方廟宇自稱、信眾俗稱或後世混融，應寫明，不拿一座廟的說法代表全台。」

## 文化背景與實用資訊

### 神明比較：用職司和脈絡選入口，不做神力排名

查「媽祖和觀音差別」「關帝和財神差別」「求健康拜誰」「神明怎麼選」的使用者，需要可理解的比較維度，而不是誰比較靈驗。

1. 內政部將媽祖的歷史與海上守護、救苦救難信仰連結，並說明信仰隨閩南移民傳入臺灣。[內政部全國宗教資訊網〈天上聖母〉](https://religion.moi.gov.tw/Knowledge/Content?ci=2&cid=241)
2. 內政部記載觀世音菩薩以救苦救難為主要民間職司，並列出送子、魚籃、千手等不同造型，適合用來解釋同一神格的地方呈現差異。[內政部全國宗教資訊網〈觀世音菩薩〉](https://religion.moi.gov.tw/knowledge/content?ci=2&cid=276)
3. 內政部記載關聖帝君具有忠義、商業財神、文衡帝君與五文昌等多重身分，說明「關公是不是財神」不能只回答是或不是。[內政部全國宗教資訊網〈關聖帝君〉](https://religion.moi.gov.tw/Knowledge/Content?ci=2&cid=286)

- **哪尊神明最靈？** 沒有可驗證的全台排名；文章比較的是來源與信仰脈絡。
- **同一個願望可以拜不同神明嗎？** 可先尊重家族和廟方規矩，避免把不同儀式的要求混在一起。
- **比較表要不要列成功率？** 不要。沒有可靠且可重現的資料，列成功率會製造不實承諾。
