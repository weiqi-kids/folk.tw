# 鬼門開、開龕門與起燈腳

農曆七月初一在基隆老大公廟稱為開龕門，地方也常說鬼門開、起燈腳。正文要把老大公廟的開門儀式、門口掛燈與整月普施的基隆脈絡寫清楚，再說明這不是每個家庭都必須照做的全臺固定時間。國史館資料與文化資產局頁面支持開龕門、普渡公燈及月底封龕門的地方敘事；2027 活動時刻仍 `年度資料待核對`。來源：[國史館臺灣文獻館](https://www.th.gov.tw/Epaper_Content/238/5723/)（`gov`）、[文化部文化資產局](https://twh.boch.gov.tw/taiwan/learn_detail.aspx?id=111)（`gov`）。
