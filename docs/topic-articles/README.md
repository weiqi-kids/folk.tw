# 52 週完整文章稿

這個目錄放的是每週一篇的「文章正文交付物」，不是題目清單，也不是只有來源的 evidence packet。`week-01.md` 到 `week-52.md` 每篇都包含：

- 可直接使用的 H1、導讀與文化脈絡正文
- 讀者常見問題（FAQ）
- 逐段可追溯的來源連結
- 既有 canonical／承接位置
- 年度資料維護欄，供發布前只更新當年度日期、路線、服務與公告

文章正文先寫 evergreen 內容，年度可變欄位不以往年資料猜填。這樣在接近節日或活動時，只需核對當年度一手公告、圖片授權、OG 與手機畫面，再回填既有 canonical；不會把 52 週變成 52 個薄頁或一次送出大量新 URL。

## 完成標準

`pnpm check:topic-articles` 會檢查：

1. 52 個週次檔案齊全且週號不跳號。
2. 每篇有標題、canonical、來源包、年度更新欄、正文、FAQ 與來源段落。
3. 正文篇幅足夠，且沒有 GA4／GSC、工具操作或「既有工具維護」等非文章主題。
4. 文章之間沒有過高的八字組合重複；共享文化背景若達警示門檻，需人工確認是否應改成互鏈。

`article-ready` 表示文章正文已備妥並通過內容 gate；它不代表年度公告或圖片 QA 已完成。年度資料未核對前，不加入 sitemap、RSS 或 IndexNow。
