# 搬家入厝、安神位與儀式分層

「搬家入厝先處理的是人、家具與新居生活；安神位則涉及神像、香爐、祖先牌位和家族傳承。兩者可以在同一段時間規畫，卻不能把『拿米桶進門』和『安爐、安座、晉火』混成一個全台固定流程。新居若有神桌或祖先牌位，先與家中長輩、原奉祀廟宇或熟悉該傳承的執事者確認，再決定日期與由誰主持。

文章可以提供檢查表：房屋交付、家人安全、神桌位置、神像來源、祖先牌位文件、廟方預約，以及地方清運和用火規範。農民曆的宜忌是民俗參考，不能取代大樓消防規定或搬家公司的安全作業。」

## 文化背景與實用資訊

### 搬家入厝與安神位：兩個儀式要拆開說

查「搬家入厝流程」「入厝要拜什麼」「安神位怎麼做」「祖先牌位何時搬」的人，需要知道搬入生活空間和安置神明／祖先牌位是不同決策。

1. 內政部把土地公（福德正神）定位為村落田土與財富的基層守護神，說明入厝時為何常見向地方土地神稟告，但不代表每間新宅都必須使用同一套供品。[內政部全國宗教資訊網〈土地公〉](https://religion.moi.gov.tw/Knowledge/Content?ci=2&cid=278)
2. 既有入厝資料把「擇日遷入、先拜地基主、安香爐」列為常見民俗脈絡；這是民間做法，應與當地大樓、社區或廟方規定分開。[信義居家〈入厝儀式全攻略〉](https://livinglife.com.tw/article/62bc06dbbc28eb00325864d5)
3. 安神位資料把神桌靠實牆、確認神位方向、安爐與安座列為常見步驟，並提醒神明爐與祖先爐不可混淆；實際儀式仍須由家族與廟方確認。[玹佑館〈安神位注意事項〉](https://www.syuanyou.com/page/about/index.aspx?kind=35&lang=TW)

- **入厝一定要和安神位同一天嗎？** 不一定；是否同日取決於家族傳承、廟方可預約時段與住宅條件。
- **租屋也能安神位嗎？** 先取得屋主同意並確認退租時如何處理；不能只照網路清單擺放神像。
- **祖先牌位可以自己搬嗎？** 先問家族長輩、原奉祀處或禮儀／宗教專業人員；各家祖先系譜與做法可能不同。
