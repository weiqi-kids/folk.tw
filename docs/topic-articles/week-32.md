# 玄天上帝香期與地方進香

南投名間松柏嶺受天宮的玄天上帝香期，不是只有農曆三月初三當天的一場生日活動。內政部宗教資訊網的廟宇資料把香期描述為從農曆正月延續到三月初三，接近玄天上帝萬壽慶典前，來自各地的寺、廟、宮、壇進香團集中到受天宮參拜；文化部國家文化資產網則將「名間鄉受天宮玄天上帝香期」列為地方民俗資料。[內政部全國宗教資訊網：受天宮慶（祭）典查詢](https://religion.moi.gov.tw/Festival/Festival?ci=1) [文化部國家文化資產網：名間鄉受天宮玄天上帝香期](https://nchdb.boch.gov.tw/assets/overview/folklore/20120913000001) 國曆日期、進香團安排和現場動線仍要依年度公告，不由農曆換算直接生成活動頁。

## 文化脈絡與實用說明

### 文化說明

南投名間松柏嶺受天宮的玄天上帝香期，不是只有農曆三月初三當天的一場生日活動。內政部宗教資訊網的廟宇資料把香期描述為從農曆正月延續到三月初三，接近玄天上帝萬壽慶典前，來自各地的寺、廟、宮、壇進香團集中到受天宮參拜；文化部國家文化資產網則將「名間鄉受天宮玄天上帝香期」列為地方民俗資料。[內政部全國宗教資訊網：受天宮慶（祭）典查詢](https://religion.moi.gov.tw/Festival/Festival?ci=1) [文化部國家文化資產網：名間鄉受天宮玄天上帝香期](https://nchdb.boch.gov.tw/assets/overview/folklore/20120913000001) 國曆日期、進香團安排和現場動線仍要依年度公告，不由農曆換算直接生成活動頁。

「香期」要用季節性窗口理解，而不是只做一個生日日期卡。受天宮資料指出，農曆正月下旬起各地進香團陸續到訪，接近三月初三時人潮與陣頭活動達到高峰；讀者搜尋「受天宮三月三」時，真正需要的是香期範圍、峰值與參拜安排的關係。這段可以回答搜尋需求，但所有香團數、每日接駕名單、停車和交通管制都要留給年度公告。[內政部全國宗教資訊網：受天宮慶（祭）典查詢](https://religion.moi.gov.tw/Festival/Festival?ci=1)

受天宮的參拜流程資料也提供了辨識場域的線索：進香團有由虎門入廟埕、經中門參拜與交香，再由中門出、龍門回駕的描述；一般參拜則以主廟殿玄天上帝等神尊和太歲殿為主要節點。這是廟方個案資料，不能改寫成全臺玄天上帝廟都必須採用的統一順序；香期期間是否調整動線，仍以現場公告為準。[內政部全國宗教資訊網：受天宮參拜流程](https://religion.moi.gov.tw/Religion/GetUploadFile?UploadFileID=70557&IndexID=4&_t=0)

玄天上帝的神明職司、別名與信仰分布屬 evergreen 神明內容；本事件頁只引用足以理解受天宮香期的背景，再連回神明頁。這種分流可以避免把「受天宮進香」和「玄天上帝是誰」做成兩個彼此重複的日期／百科頁。[內政部全國宗教資訊網：玄天上帝](https://religion.moi.gov.tw/Knowledge/Content?ci=2&cid=280)

- 文化部國家文化資產網收錄「南投縣名間鄉受天宮玄天上帝香期」，資料庫標示為南投地方民俗，並把受天宮視為玄天上帝信仰中心。（範圍：文化資產登錄可支撐文化脈絡，不代表每年活動都有相同規模或固定路線。；來源：[文化部國家文化資產網](https://nchdb.boch.gov.tw/assets/overview/folklore/20120913000001)）
- 內政部宗教資訊網的受天宮資料記錄香期從農曆正月至三月初三，三月初三玄天上帝萬壽慶典前後為高峰，並有各地進香團集中參拜的描述。（範圍：農曆窗口是常年資料；2027 國曆日、香團名單、數量與現場安排必須重新取得年度公告。；來源：[內政部全國宗教資訊網：慶（祭）典查詢](https://religion.moi.gov.tw/Festival/Festival?ci=1)）
- 內政部宗教資訊網的受天宮參拜流程記錄進香團由虎門入廟埕、經中門參拜交香，再由中門出、龍門回駕的廟方動線。（範圍：這是受天宮個案流程，不可推廣成臺灣所有進香團固定規則；活動期間可能依現場管制調整。；來源：[內政部全國宗教資訊網：受天宮參拜流程](https://religion.moi.gov.tw/Religion/GetUploadFile?UploadFileID=70557&IndexID=4&_t=0)）
- 內政部全國宗教資訊網的玄天上帝條目提供「北極大帝／真武大帝／上帝公」等名稱及鎮邪驅魔、北方水神等信仰職司，可用作事件頁的短背景。（範圍：這是神明通用背景，不可用來證明受天宮年度行程或所有廟宇的參拜方式。；來源：[內政部全國宗教資訊網：玄天上帝](https://religion.moi.gov.tw/Knowledge/Content?ci=2&cid=280)）
- 受天宮資料把主祭活動列在農曆三月初三，並將受天宮的主神、廟址與進香中心身分分開記錄；事件頁可據此做地點與日期辨識。（範圍：不以廟宇資料自動補出國曆日期、當日活動時間或交通資訊。；來源：[內政部全國宗教資訊網：受天宮慶（祭）典查詢](https://religion.moi.gov.tw/Festival/Festival?ci=1)）

## 常見問題

**受天宮玄天上帝香期是哪一天？**
常年資料是農曆正月至三月初三，農曆三月初三聖誕前後達到高峰；這是一段香期，不是只有單日。2027 年國曆落點與活動安排要等年度官方資料，不能以往年國曆日直接套用。

**受天宮三月三和玄天上帝香期一樣嗎？**
三月初三是香期的高峰與玄天上帝萬壽慶典，香期則從農曆正月延續到三月初三前後；兩者相關但不等義。本文會用日期軸呈現，而非只放一個三月三活動卡。

**進香團參拜一定要走虎門、中門、龍門嗎？**
受天宮的官方參拜資料記錄進香團動線，但這是受天宮個案；實際香期現場可能因人流與安全調整，請以廟方現場指示為準，不把它寫成全臺通則。[受天宮參拜流程](https://religion.moi.gov.tw/Religion/GetUploadFile?UploadFileID=70557&IndexID=4&_t=0)

**可以自己安排一日進香嗎？**
是否需要登記、交香、接駕或配合特定時段，屬廟方年度服務規則。沒有當年度公告時，本頁只提供文化與地點背景，不承諾個人進香的報名、停車或交通安排。

**玄天上帝頁和受天宮香期頁有什麼不同？**
`/deities/xuantian/` 回答神明名稱、職司與信仰脈絡；本頁回答名間受天宮的季節性進香活動、廟方流程與年度公告。兩者互相連結但不重複全文。
