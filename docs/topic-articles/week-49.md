# 祈福事件後續如何查證

「祈福頁的後續不是把新聞標題再貼一次，而是為同一事件建立可追溯時間線。每一則更新至少要記錄發布時間、事件地點、資訊來源、原文對象和目前狀態；救援、傷亡、復原與交通恢復應分欄，不能用『解除警報』推論所有人都已恢復正常。

查證時先找地方政府、氣象、消防、醫療或救災機關，再用兩家可靠媒體交叉比對；若不同來源仍有落差，就保留不確定性。事件頁要讓讀者看得到更新，不只是 Slack 已經收到通知；每次上稿後都要檢查 canonical、頁面時間線、OG 和手機畫面。」

- **只看到一則新聞可以發布更新嗎？** 可以先標為待交叉核對，不要把單一來源寫成確定結論。
- **「解除警報」能不能寫成事件結束？** 不能；要看人員、基礎設施、交通和地方機關是否還有後續。
- **同一事件有兩個網址怎麼辦？** 以事件識別和地點合併到一個 canonical，將不同報導作為 timeline facts，除非確實是不同事件。
