# 安太歲、點燈、補運、還願詞彙差異

「民俗活動的名稱往往只有兩三個字，實際上卻指向不同的行動。遶境重點在神明鑾轎巡行本境、安定地方；進香重點在前往他廟或祖廟謁祖、延續香火；遶境進香是兩種目的疊在同一場活動裡；刈香則常指聯境赴祖廟取火再返境的複合儀式。迎王又是恭迎代天巡狩王爺入境的地方祭典，不能看到有王船就把所有活動叫成同一個詞。

詞彙頁要顯示定義、來源、常見例子和『不等於什麼』，並把年度活動回鏈到主辦方資料。地方社群有自己的稱呼時，保留原名並說明使用範圍，不強迫全台使用同一個標準。」

## 文化脈絡與實用說明

### 51. 儀式詞彙差異：遶境、進香、刈香和迎王不能混用

查「遶境和進香差別」「刈香是什麼」「迎王是不是遶境」「安座和安神位差在哪」的人，需要短而精準的詞彙卡與相互連結。

「民俗活動的名稱往往只有兩三個字，實際上卻指向不同的行動。遶境重點在神明鑾轎巡行本境、安定地方；進香重點在前往他廟或祖廟謁祖、延續香火；遶境進香是兩種目的疊在同一場活動裡；刈香則常指聯境赴祖廟取火再返境的複合儀式。迎王又是恭迎代天巡狩王爺入境的地方祭典，不能看到有王船就把所有活動叫成同一個詞。

詞彙頁要顯示定義、來源、常見例子和『不等於什麼』，並把年度活動回鏈到主辦方資料。地方社群有自己的稱呼時，保留原名並說明使用範圍，不強迫全台使用同一個標準。」

1. 內政部臺灣宗教文化地圖把遶境描述為神明出廟巡行轄境、收煞護民的儀式，可作為與進香區分的第一個基準。[臺灣宗教文化地圖〈遶境〉](https://taiwangods.moi.gov.tw/html/cultural/3_0011.aspx?i=27)
2. 同一資料把進香與刈火放在赴他廟／祖廟謁祖、延續香火的脈絡；刈香還涉及聯境共同出發和返境儀式，不能只翻成「去拜拜」。[臺灣宗教文化地圖〈進香〉](https://taiwangods.moi.gov.tw/html/cultural/3_0011.aspx?i=15)
3. 客家文化資產網的迎王資料把迎王放在代天巡狩王爺、王船和地方祭典脈絡，與一般遶境的定義不同。[客家文化發展中心〈迎王平安祭典〉](https://twinheritagenet.hchcc.gov.tw/ch/home.aspx?ID=$4139)
4. 內政部宗教資料中的「安太歲」是年度祈福服務，不應因為也有「安」字就與安座、安神位視為同一詞。[內政部全國宗教資訊網〈安太歲〉](https://religion.moi.gov.tw/Knowledge/Content?ci=2&cid=44)

- **遶境就是進香嗎？** 不完全是；一個偏向本境巡行，一個偏向赴他廟謁祖，複合活動才會同時使用兩個詞。
- **刈香和刈火是同一個詞嗎？** 常有關聯，但本文會依地方活動的原始用語與程序說明，不能自行替換。
- **迎王一定有王船嗎？** 王船是常見象徵，仍要以該地祭典的登錄資料與主辦方公告為準。
