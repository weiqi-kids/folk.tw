# 口湖牽水車藏

口湖牽水車藏在農曆六月初七至初九舉行，內容是追思道光二十五年（1845）六七水災罹難者。文化部資料將它列為國家重要民俗，內政部宗教文化地圖也指出其源自真實歷史災難事件。來源：文化部國家文化資產網（https://nchdb.boch.gov.tw/assets/overview/folklore/20081125000001，`gov_heritage`）與內政部臺灣宗教文化地圖（https://taiwangods.moi.gov.tw/html/cultural/3_0011.aspx?i=269，`moi_religion`）。本文會先交代追思與地方記憶，再寫儀式觀看資訊；不要把「牽水車藏」改寫成一般中元普渡流程。2027 的活動場地、交通與是否調整，等雲林縣政府／主辦方公告。
