# 放水燈與中元前置儀式

基隆放水燈在農曆七月十四、普渡前一天舉行，地方稱為普照陰光。本文會先交代海港城市把水燈視為通知海上受難者參加隔日普度的追思儀式，再處理遊行、下水與觀賞資訊；不能把水燈寫成全臺同一天的觀光燈會。2027 路線、封路與下水地點等候基隆主辦方公告。來源：[國史館臺灣文獻館](https://www.th.gov.tw/Epaper_Content/238/5723/)（`gov_museum`）。
