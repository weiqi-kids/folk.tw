# 保生大帝藥籤・內容產製規格

> **這份文件是產製規格，不是給醫師填空的表單。**
> 六個欄位的內容**由我們先做出來**，醫師的角色是**審閱與修正**。
> ⚠️ **2026-08-06 實查更正**：`yaoqian-notes.json` 實際只有 5 個 key
> （`id`／`specialty`／`safety_flags`／`why_not_self_medicate`／`modern_care_pathway`／`physician_note`），
> **`modern_identification` 與 `known_pharmacology` 兩欄從未落地**（全 repo 0 命中）——
> 它們是產製過程的中間產物，沒有存進資料層。本檔以下描述六欄位處請以此為準。
> 定稿 2026-07-31。欄位名即 JSON key，改欄位要同步改 `check:integrity`。

## 一、專案定位（醫師審閱前請先讀）

我們**不是**要提供可用的藥方，也不是要主張藥籤有效。

- **民國 88 年（1999）**，衛生署因藥籤管理不當遭監察院糾正，隨後**明文禁止使用藥籤**。
- 另一方面，**衛生福利部國家中醫藥研究所**已將這批藥籤數位典藏，
  經文化部「國家文化記憶庫」以 **PDM（公有領域標章）** 公開。

也就是說：**作為醫療手段已被明令禁止，作為民俗文獻則由政府自己保存並開放。**

本專案做的是後者，並補上前者缺的那一塊——
**具名醫師說明「這是什麼、為什麼不能照著用、真的不舒服該去哪裡」**。

目前網路上的藥籤網站都只把藥方貼出來，沒有一家說明它已被禁用，也沒有一家有醫師具名。

## 二、產製流程

```
① 事實層（我們查證後直接填好，逐條掛來源）
   ├─ modern_identification   藥材現代名稱與基原
   └─ known_pharmacology      現代藥學上已知的作用

② 科別推估（依藥方組成判斷對應的現代科別）
   例：木賊＋穀精草（明目退翳）＋龍膽草（瀉肝膽火）→ 眼科

③ 判斷層（以「該科＋中醫科雙主修醫師」人格 prompt 起草）
   ├─ safety_flags            安全警示
   ├─ why_not_self_medicate   為什麼不能照著抓藥
   ├─ modern_care_pathway     真的不舒服該去哪裡
   └─ physician_note          醫師自由說明

④ 醫師審閱 → 修正 → 具名
```

✅ **330 首已審閱完畢**（用戶 2026-08-06 確認）。

⚠️ 上面第 ④ 步的「具名」與本節原本寫的「資料層以 `physician_reviewed: false` 標記、
`check:integrity` 硬擋」**都沒有實作，也不會實作**：
- 用戶明確表示**不要在頁面上寫審閱狀態**——授權、來源與原始典藏警語已由
  `/medicine-slips/` 樞紐頁與 `/about/` 統一處理，逐首頁再加就是多餘的警語。
- 因此資料層沒有 `reviewed_by`／`physician_reviewed`，`check:integrity` 也沒有對應 gate。
  **這是刻意的，不是漏做。** 不要「補上」。

🔴 **頁面上仍不掛醫師姓名、不宣稱由醫師撰寫。** 這條不因審閱完成而改變。

## 三、科別推估規則（步驟 ②）

依藥方**主要藥材的歸經與功效**判斷，而非依藥籤原本的科別分類。

> ⚠️ **藥籤自己的「大人科／小兒科／外科／眼科」分類，與現代科別不對應。**
> 實例：大人科第 44 首的組成其實明確指向眼科（見下方實例）。

| 藥方主要指向 | 現代科別 | 人格 prompt |
|---|---|---|
| 明目退翳（木賊、穀精草、決明子…） | 眼科 | 眼科＋中醫科雙主修醫師 |
| 瀉肝膽火、黃疸（龍膽草、茵陳…） | 肝膽腸胃科 | 肝膽腸胃科＋中醫科雙主修醫師 |
| 化痰止咳平喘（川貝、半夏、杏仁…） | 胸腔內科 | 胸腔內科＋中醫科雙主修醫師 |
| 婦科調經、安胎 | 婦產科 | 婦產科＋中醫科雙主修醫師 |
| 小兒疳積、驚風 | 小兒科 | 小兒科＋中醫科雙主修醫師 |
| 瘡瘍腫毒、跌打 | 外科／骨科 | 外科＋中醫科雙主修醫師 |
| 組成分散、無明確指向 | 家庭醫學科 | 家醫科＋中醫科雙主修醫師 |

**人格 prompt 樣板**：

```
你是一位【○○科】專科醫師，同時具中醫師資格，臨床上經常需要向病人解釋
民間偏方與中藥的風險。

以下是一首保生大帝藥籤的藥方原文，以及已查證的藥材現代名稱與已知藥理作用。
請以「向病人／家屬口頭說明」的語氣撰寫四段內容。

鐵則：
- 不得主張這帖方有療效，也不得指導如何使用。
- 只能依據下方提供的已查證資料推論，不得引入未提供的藥理主張。
- 不確定的地方直接說「原文未載，無法判斷」，不要補齊。
- 語氣是真人醫師講話，不要有 AI 腔（不寫「總的來說」「值得注意的是」這類套語）。
- 台灣用語、繁體中文。

【藥方原文】…
【藥材現代名稱與基原】…
【已知藥理作用】…

請輸出四段：safety_flags / why_not_self_medicate / modern_care_pathway / physician_note
```

## 四、完整實例：大人科第 44 首

> 以下是照上述流程實際跑出來的成品。**③ 的四段為待審草稿。**

### 藥方原文（國家文化記憶庫典藏，PDM）

> 白朮、連喬、木賊、谷精、錢半、川貝、半夏各一錢、膽草四分。水碗半煎七分。

### ① `modern_identification` — 藥材現代名稱與基原

| 籤文用字 | 現代名 | 學名／基原 |
|---|---|---|
| 白朮 | 白朮 | *Atractylodes macrocephala* 根莖 |
| **連喬** | **連翹** | 木犀科 *Forsythia suspensa* 之果實 |
| 木賊 | 木賊 | 木賊科 *Equisetum hyemale* 地上部 |
| **谷精** | **穀精草** | *Eriocaulon buergerianum* 帶花莖頭狀花序 |
| 川貝 | 川貝母 | *Fritillaria cirrhosa* 等之鱗莖 |
| 半夏 | 半夏 | *Pinellia ternata* 塊莖 |
| **膽草** | **龍膽草** | 龍膽科 *Gentiana* spp. 根及根莖 |

⚠️ **「錢半」不是藥材，是劑量（一錢半）。** 它夾在藥材列之中，抄本易被誤讀成第五味藥。
本站保留原文不改，但在此標明——**這正是外行人照抄會出錯的第一關**。

### ② 科別推估

木賊＋穀精草是明目退翳的典型配對，龍膽草瀉肝膽火（中醫「肝開竅於目」），
整方指向**目赤腫痛**一類。→ **眼科**，人格 prompt ＝ 眼科＋中醫科雙主修醫師。

> 注意：本籤在藥籤裡歸「**大人科**」，但組成指向眼科。分類與現代科別不對應。

### ③ `known_pharmacology` — 現代藥學上已知的作用（逐條掛源）

| 藥材 | 已知作用 | 來源 |
|---|---|---|
| 連翹 | 苦、微寒，入心膽經，清熱解毒。具廣譜抗菌作用，對金黃色葡萄球菌、志賀氏痢疾桿菌抑制作用強；含三萜皂苷、連翹酚、齊墩果酸、香豆素類與維生素 P | 台灣中醫藥資訊網／新北市藥師公會《中藥學堂・連翹》 |
| 龍膽草 | 苦寒，入肝、膽經，清熱燥濕、瀉肝膽火 | 台灣中醫藥資訊網 |
| 半夏 | 燥濕化痰。**生半夏有毒**：生食 0.1–0.8 g 即可中毒，服後 30 分鐘至 2 小時出現症狀；輕者口舌咽喉灼痛、流涎、噁心嘔吐，重者失音、呼吸困難、喉頭水腫致窒息。**孕婦、陰虛火旺者禁用**；**忌與烏頭類同用** | 醫砭・常用中藥；香港衞生署中醫藥規管辦公室 |
| 川貝母 | 化痰止咳，臨床常與半夏配伍治痰多咳嗽 | 醫砭・常用中藥 |
| 白朮 | 健脾燥濕，常與半夏、天麻配伍（半夏白朮天麻湯）治濕痰眩暈 | 醫砭・常用中藥 |
| 木賊、穀精草 | 疏風明目退翳（傳統功效）。**現代藥理研究資料不足，本欄不填**——無源不發佈 | — |

### ④ 待審草稿（人格：眼科＋中醫科雙主修醫師）

**`safety_flags`（安全警示）**

> 這帖方裡最需要注意的是**半夏**。籤上只寫「半夏」兩個字，沒有說是生半夏還是製半夏——
> 這兩者差別是會出人命的。生半夏對黏膜有強烈刺激性，文獻上生食 0.1 到 0.8 公克就可能中毒，
> 從口舌灼痛、流口水、嘔吐，一路到失聲、呼吸困難，嚴重的喉頭水腫會窒息。
> 半夏也**忌與烏頭類藥材同用**，這是十八反裡的老規矩，不是可以商量的。
>
> **孕婦不要碰這帖。** 半夏是孕婦禁忌，陰虛火旺體質的人也不適合。
>
> 龍膽草和連翹都是苦寒藥，脾胃虛寒、容易腹瀉的人吃了會更不舒服。
> 龍膽草走肝膽經，正在服用肝臟代謝藥物的人要格外小心。

**`why_not_self_medicate`（為什麼不能照著抓藥）**

> 第一，**這張籤上的「錢半」不是藥材，是劑量**。光是這一點，照著唸給藥房聽就會抓錯。
>
> 第二，**古制的「錢」「分」跟現在的公克不能直接換算**，不同朝代、不同地方的度量都不一樣。
> 你查到的換算表未必是這張籤寫成的那個年代用的。
>
> 第三，**中藥要辨證**。同樣是眼睛紅，肝火上炎跟陰虛火旺的用藥是相反的，
> 苦寒藥用在虛證身上會越吃越糟。籤詩不會看你的舌頭、不會把你的脈。
>
> 第四，**藥材基原會變**。「川貝」現在市面上就有好幾種來源，價差十倍，藥性也不同。
>
> 最後——**衛生署在民國 88 年就已經明文禁止使用藥籤了。** 這不是我個人保守，是主管機關的決定。

**`modern_care_pathway`（真的不舒服該去哪裡）**

> 這帖方的組成主要指向眼睛的問題。如果你有**眼睛紅、癢、痛、有分泌物、畏光、視力變化**，
> 請直接掛**眼科**。眼睛的紅有很多種，結膜炎、角膜炎、虹彩炎、青光眼急性發作處理方式完全不同，
> 其中青光眼急性發作拖幾個小時就可能傷到視神經，這不是可以等的。
>
> 如果你的困擾其實是**長期咳嗽有痰**（方中有川貝、半夏），請看**胸腔內科**或**家醫科**。
>
> 想走中醫這條路也完全可以——請掛**合格中醫師門診**，讓醫師當面辨證後開方。
> 中醫的價值在辨證論治，不在照抄古方。
>
> ⚠️ 原文未載適應症，以上是就藥材屬性推想的方向，**不代表這張籤主治這些病**。

**`physician_note`（醫師自由說明）**

> 我在門診遇過拿著手機截圖來問「醫師這個可以吃嗎」的病人，其實不少。
> 我通常不會直接說「這是迷信」，因為對很多人來說，去廟裡求一支籤是走投無路時的一種安頓。
> 那個心情是真的。
>
> 但藥籤有個結構性的問題：**它給方，卻常常不說治什麼**。這張第 44 首就沒有適應症。
> 一個不知道自己在治什麼的方子，你要怎麼判斷有沒有效、什麼時候該停？
>
> 從中醫的角度看，這張方的思路其實是清楚的——清肝火、退目翳，配一點化痰健脾顧著脾胃。
> 開方的人是懂的。問題從來不在古人，在於**那個人當年是看著病人開的，而籤筒不是**。

## 五、醫師審閱時要看什麼

請醫師針對每一首確認四件事，改哪裡直接改：

1. **事實有沒有錯**（藥材基原、藥理敘述、毒性劑量數字）
2. **科別推估對不對**（若不對，請指出應為哪一科，我們會換人格 prompt 重跑）
3. **有沒有漏掉的安全警示**（尤其交互作用與特殊族群）
4. **語氣像不像真人醫師講話**（本站有去 AI 腔的自動檢查，但人眼仍是最後一關）

審畢請提供：姓名、專科別、執業執照字號（是否公開顯示可再議）、審閱日期。
