## 為什麼要做這件事

站上的籤系母體是成長的瓶頸。2026-08-20 的 GSC 分析：籤詩頁的每頁產值是廟宇頁的
數倍（判準與量法見記憶 `demand-corpus-pivot`），但籤詩頁只有兩百多頁而廟宇頁近萬頁。
要擴籤系就要有**權威、完整、版本錨定**的籤本全文——而那正是先前一直卡住的地方。

台灣端 2026-08-02 交付的 `inbox/misc/TEMPLE-QIANBAN-LIST.md` 給了 33 件臺史博籤詩藏品，
但當時把它記成「線索池」就停住了，卡點被寫成「找到了要有人去問廟方」。

**2026-08-20 查證後，那個卡點的敘述是錯的**：要問的不是各廟方，是**典藏單位**。
`collections.culture.tw` 的著作權聲明明白寫著，利用藏品資料需「逕向各典藏單位洽詢」，
而這 33 件的典藏單位全部是同一個——國立臺灣歷史博物館。**一個窗口，不是十幾通電話。**

## 🔴 兩層授權要分開看，混在一起就會判斷錯

| 層 | 對象 | 狀態 |
|---|---|---|
| 籤文本身 | 清代／日本時代的籤詩文字 | **公眾領域**，著作權早已消滅 |
| 數位影像 | 臺史博拍的照片／掃描檔 | 逐件不同，看該件的「圖片授權聲明」標章 |

所以「這件能不能用」問的**不是籤文有沒有版權**，是**看得清楚的影像從哪來**。

## 逐件盤點怎麼做的

臺史博典藏網的詳目頁可以用登錄號直接開：

```
https://collections.nmth.gov.tw/CollectionContent.aspx?a=132&rno=<登錄號>
```

頁上有一個 `圖片授權聲明` 區塊，掛的是授權標章圖（`images/PDM.png` 這種）。
逐件抓那個標章，每件 1 次請求、間隔 1.2 秒，結果寫進
[`qian-collections-nmth.json`](qian-collections-nmth.json)，每件標一個 `usability`：

| `usability` | 標章 | 能不能用 |
|---|---|---|
| `free` | PDM 公眾領域標章／CC0 公眾領域貢獻宣告 | ✅ 可自由使用 |
| `noncommercial` | CC BY-NC 姓名標示─非商業性 | ⚠️ 非商業才可用，**先確認站主的商業模式立場** |
| `blocked` | 僅限瀏覽 | ⛔ 不可用 |
| `unmarked` | 頁上沒有授權標章 | ❓ 未知，要問館方，**不可預設可用** |

🔴 **`noncommercial` 那一件不要當成可用**：站上不接受業配但不排除廣告投放，
且規劃 NFC 抽籤這類產品（見 `src/pages/about.astro` 檔頭），未必算非商業使用。
要用它得站主先表態。

🔴 **`unmarked` 不等於可用**。「頁上沒標」只代表館方沒宣告，不代表放棄權利。

## 卡在哪裡：解析度

典藏網公開的影像只有長邊 640px（實測 425×640），而像「宜蘭城隍廟101首籤詩」是
一整疊籤條拍成一張照片，**逐首判讀不可能**。籤文要抄下來就得拿到高解析檔。

即使是 PDM 的件，高解析檔仍要走典藏授權申請取得——PDM 解除的是「能不能用」，
不是「檔案在哪裡」。

## 申請管道（臺史博典藏授權）

- 線上申請入口：<https://collections.nmth.gov.tw/> →「典藏授權／開始申請」
- 用途：館方申請說明明列「學術研究、教育、推廣、展示、出版」等用途
- 流程：於典藏網提出申請 → 約 2 個工作天通知審核結果 → 免收費案件在申請資料寄達後
  約 3 個工作天提供檔案（機關、學校可行文辦理）；需收費案件則匯款後提供
- 收費依據：館方公告的「圖像影音及出版品資料使用收費標準」與「收費作業要點」
  （兩份附件在申請說明頁可下載）
- 承辦窗口：顏小姐，`o1081002@nmth.gov.tw`，06-3568889 分機 2226
  （週一至週五 09:00–12:00、13:30–17:30）

⚠️ **申請時的用途欄要照實填**。folk.tw 是公開網站且不排除廣告投放，
填「非商業」之前先確認站主的立場——填錯比不申請更糟。

- 觀音一百籤：唯一完整且版本錨定的線索是臺文館藏「觀音籤譜」`NMTL20060200544`，

### 文化部「國家文化記憶庫」開放資料集：查過了，沒有籤本全文（2026-08-20）

這條路值得查，因為藥籤那批 PDM／OGDL 就是從同一個平台家族（`tcmb.culture.tw`）來的，
而且它在 data.gov.tw 有**政府資料開放授權條款第 1 版**的資料集，每筆帶
`imageLicense`／`contentLicense` 欄位——完全不必申請。端點：

```
https://tcmbdata.culture.tw/opendata/dataSet/culture?subject=<類別>&page=<頁>
```

類別代碼在各自的 data.gov.tw 頁面上（`ART_AND_HUMANITY`、`OTHER`、`PEOPLE_AND_GROUP`…），
每頁 20 筆，`total` 在回應裡。

**實際跑了 `ART_AND_HUMANITY` 與 `OTHER` 兩類全量**（每頁間隔 1.1 秒），
標題／描述／關鍵字命中「籤」的素材裡，**標題或關鍵字真的在講籤的只有 5 筆**，
其餘全是誤命中（標籤、地瓜籤、竹籤、古籍描述提到籤）。那 5 筆全是 CC BY 的照片
（藥籤筒、藥籤簿、廟宇建築、影音），**沒有一筆是籤本全文**。

⛔ **結論：這條路對擴籤系無用，不要再跑**。⚠️ 已知限制：只跑了上述兩類，
其餘類別（人物與團體、生物生態與環境、社會與政治、族群與語言、空間地域與遷徙）沒跑——
但籤詩若有，落在那幾類的機率很低。另 `ART_AND_HUMANITY` 有一頁發生 3 次瞬時連線失敗後重試成功。
